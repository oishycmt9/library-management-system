# Library Management System

A web-based Library Management System developed using Laravel 13.

## Features

- Admin Dashboard
- User Management
- Category Management
- Author Management
- Publisher Management
- Book Management
- Borrowing Management
- Order Management
- Payment Management
- REST API
- Book Stock Management

## Technologies Used

- PHP
- Laravel 13
- MySQL
- Bootstrap 5
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/oishycmt9/library-management-system.git
   ```

2. Go to the project directory:

   ```bash
   cd library-management-system
   ```

3. Install dependencies:

   ```bash
   composer install
   ```

4. Create the environment file:

   ```bash
   cp .env.example .env
   ```

5. Generate application key:

   ```bash
   php artisan key:generate
   ```

6. Configure your database in the `.env` file.

7. Run migrations:

   ```bash
   php artisan migrate
   ```

8. Start the development server:

   ```bash
   php artisan serve
   ```
