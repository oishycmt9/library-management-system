# Library Management System

A web-based Library Management System developed using Laravel 13.

## Features

- Admin Dashboard
- User Management
- Category Management
- Author Management
- Publisher Management
- Book Management
- Borrowing Management
- Order Management
- Payment Management
- REST API
- Book Stock Management

## Technologies Used

- PHP
- Laravel 13
- MySQL
- Bootstrap 5
- HTML
- CSS
- JavaScript
